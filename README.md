# Student Task Manager

## 1. Project Overview

The **Student Task Manager** is a web-based application designed to help students organize, allocate, and manage assignments belonging to different subjects. It provides a centralized platform where students can record their names, assign tasks to specific subjects, and keep track of their academic assignments in an organized manner.

The main objective of this project is to simplify assignment management, improve productivity, and help students keep their academic work organized in one place.

## 2. Features

- **Student Name Recording:** Record student names associated with assignments.
- **Subject-Wise Assignment Management:** Organize assignments according to different subjects.
- **Task Allocation:** Allocate assignments to students and their respective subjects.
- **Task Tracking:** View and manage recorded assignments.
- **Centralized Management:** Keep assignment information organized in one application.
- **User-Friendly Interface:** Simple and accessible interface for managing academic tasks.
- **Organized Display:** View task details, including student names, subjects, and assignments.

## 3. Technologies Used

- **HTML5:** Structures the web application's content.
- **CSS3:** Styles the interface and improves its visual appearance.
- **JavaScript:** Implements the application's interactive functionality.

## 5. How to Run the Project

### Prerequisites
- A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
- A code editor such as Visual Studio Code (optional).

### Steps

1. Download or clone this repository to your computer.
2. Extract the downloaded ZIP file if necessary.
3. Open the project folder.
4. Locate the `index.html` file.
5. Double-click `index.html` to open the application in your browser.

Alternatively, open the project folder in Visual Studio Code and run `index.html` using the Live Server extension.

## 6. How to Use

1. Open the Student Task Manager application.
2. Enter the student's name.
3. Select or enter the relevant subject.
4. Enter the assignment or task details.
5. Allocate and record the assignment using the available controls.
6. View and manage the recorded assignment details through the interface.

The exact steps depend on the controls implemented in the application.

## 7. Benefits

- Helps students organize assignments subject by subject.
- Makes it easier to associate tasks with student names.
- Reduces confusion when managing multiple assignments.
- Provides a centralized view of academic tasks.
- Encourages better organization and time management.

## 8. Future Enhancements

Possible future improvements include:

- Assignment deadlines and reminders.

## 9. Intended Users

This application is intended for students who want a simple way to record, allocate, and organize assignments across multiple subjects.

## 10. Conclusion

The Student Task Manager provides a simple web-based solution for organizing academic assignments. By connecting student names, subjects, and assignment details in one place, it aims to make assignment management easier, clearer, and more efficient.
